# Twitter Clone (Part 84)

This project is a frontend clone of Twitter (X) built using HTML and Tailwind CSS.

## 🚀 Features

* Sidebar navigation (Home, Explore, Notifications, etc.)
* Tweet posting UI
* Feed layout similar to Twitter
* Right sidebar with trends and suggestions
* Responsive dark theme design

## 🛠️ Tech Used

* HTML
* Tailwind CSS

## 📂 Project Structure

* `index.html` – Main layout
* Tailwind CSS for styling

## 📸 Preview

A basic Twitter UI clone created as part of learning web development.

## 📌 Note

This is a practice project and not a full functional clone.
